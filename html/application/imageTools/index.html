  • 百分比调整：按原始图片尺寸的百分比进行调整
    • 可选择25%、50%、75%等常用比例
    • 自动保持原始宽高比
    • 适合需要等比例缩放的场景
  • 像素调整：直接指定目标像素尺寸
    • 可选择预设的常用尺寸
    • 自动保持原始宽高比
    • 适合需要特定尺寸的场景
  • 自定义：手动输入目标尺寸
    • 可自由设置宽度和高度
    • 可选择是否保持宽高比
    • 适合有特殊尺寸要求的场景

支持的图片格式

  • JPEG/JPG：适合照片和复杂图像
  • PNG：适合图标、截图等需要保持清晰边缘的图像
  • BMP：常见的无压缩位图格式
  • GIF：支持简单动画的图片格式（注：调整后将失去动画效果）

使用建议

  1. 根据使用场景选择合适的调整模式：
    • 网站图片建议使用"百分比调整"模式
    • 社交媒体图片建议使用"像素调整"模式
    • 特殊需求使用"自定义"模式
  2. 调整前请备份原始图片
  3. 调整后请检查图片质量是否满足需求
  4. 建议保持原始宽高比，除非有特殊需求
  • 缩小优先：适用于需要大幅减小文件大小的场景
    • 压缩质量设置为60%
    • 自动限制最大尺寸为1920像素
    • 适合网站图片、邮件附件等场景
  • 清晰优先：适用于需要保持较高图片质量的场景
    • 压缩质量设置为90%
    • 保持原始尺寸
    • 适合摄影作品、打印图片等场景
  • 按质量调整：手动指定压缩质量
    • 可调节压缩质量（0-100%）
    • 适合需要精细控制画质的场景
  • 按大小调整：指定目标文件大小自动压缩
    • 自动二分搜索最佳质量参数
    • 使输出大小尽量接近目标值
    • 适合有特定大小限制的场景

支持的图片格式

  • JPEG/JPG：适合照片和复杂图像，支持高压缩率
  • PNG：适合图标、截图等需要保持清晰边缘的图像
  • BMP：常见的无压缩位图格式
  • GIF：支持简单动画的图片格式（注：压缩后将失去动画效果）

使用建议

  1. 根据使用场景选择合适的压缩模式：
    • 网站图片建议使用"缩小优先"模式
    • 重要图片建议使用"清晰优先"模式
    • 特殊需求使用"按质量调整"或"按大小调整"
  2. 压缩前请备份原始图片
  3. 压缩后请检查图片质量是否满足需求
  4. 对于大尺寸图片，建议先调整尺寸再进行压缩

支持的格式

  • JPEG/JPG
    • 适合照片和复杂图像
    • 支持质量调整（0-100%）
    • 有损压缩，文件较小
  • PNG
    • 适合图标、截图等需要保持清晰边缘的图像
    • 支持透明度
    • 无损压缩，文件较大
  • WebP
    • 现代高效的图片格式
    • 支持有损和无损压缩
    • 文件大小比JPEG和PNG更小
  • BMP
    • 无压缩位图格式
    • 保持原始图像质量
    • 文件较大

使用建议

  1. 根据使用场景选择合适的格式：
    • 照片使用JPEG格式
    • 需要透明度的图片使用PNG格式
    • 网页图片优先使用WebP格式
    • 需要原始质量的图片使用BMP格式
  2. 转换前请备份原始图片
  3. 注意不同格式的特点和限制
  4. 合理设置图片质量以平衡文件大小和图片质量
