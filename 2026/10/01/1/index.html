Realtek Cortina

发表于 2026-10-01 本文字数： 1.5k 阅读时长 ≈ 6 分钟
家用 ONU/ONT 设备的 Realtek 10G PON 芯片系列，源自 Cortina 原厂 CA8277B ARM 硅片。

Realtek Cortina 是 Realtek 为 ONU/ONT 设备提供的 10G PON 芯片系列，源自 Cortina 原厂 CA8277B ARM 硅片。Realtek 收购/授权 Cortina 的技术后，将其芯片重新包装为 Realtek 品牌，并在 SDK 中以 Luna 为平台主干，统管 Taurus、Elnath、Mercury 等不同型号。

该 SoC 具备4× Cortex-A55 @ 可配至 1.2GHz、GICv3、DDR3/4 至 4GB、eMMC HS200、Cortina NI+PE 交换/PON 引擎（4 RGMII 口 + 内部口 + GPON/EPON + 多 SerDes）、3× PCIe x1 Gen2、USB2×2+USB3×1、双加密引擎、I2C×2/SPI×2/UART×3~4 等

一、代号

  • Cortina（Cortina Access）：原始硅片 IP 厂商，提供 CA8277B/CA8277C die 及 Venus / G3 / G3HGU / Presidio 等自有代号。Realtek 收购/授权其 10G PON 技术后，把这些芯片以 RTL 料号重新包装。

  • Luna：不是芯片，而是 SDK/平台主干名（Realtek ASDK）。它统管下面所有 Realtek 品牌的 10G PON 芯片。

  • Taurus / Elnath / Mercury / Venus / 9617D：具体 芯片/板级代号，映射到不同的 Realtek 或 Cortina 料号与内核 arch 开关。

  • G3 / G3HGU / Presidio：代码里出现的其它 Cortina 参考代号（有独立 CORTINA_BOARD_G3_ENG / G3HGU_ENG / presidio-asic 目录），与 CA8277B 家族分开。

这些子型号硬件/驱动框架完全一致，只由子型号选出不同的端口数与功能档位。

四、一句话关系图

简言之：Luna 是 SDK 名；Cortina 是原始硅片来源；Venus/Taurus/Elnath/Mercury/9617D 都是同一 CA8277B 上的芯片代号，分别被打上 Cortina 或 Realtek 料号（8277C / 9617C / 9607F / Mercury 等），其中 9617 只是 Taurus 家族的一个子型号。

  • 外部定时器 25 MHz、APB dw_pclk 100 MHz、另一参考 125 MHz

六、网络加速

这套 SoC 硬件上是 NI（Network Interface）+ PE（Packet Engine） 引擎，软件侧是 FleetConntrack（FC）流卸载框架 + RomeDriver（RG）路由引擎 + Switchdev。

硬件数据面引擎

SoC 内置的转发引擎由两大部分组成：

  • NI（Network Interface）：交换/转发主引擎，含 L2FE（L2 转发引擎）、L2TM、L3FE（L3 转发引擎）、TQM（流量队列管理器），并集成 GPON/EPON PON MAC 与多路 SerDes（SGMII/XFI/QX）。

  • PE（Packet Engine）：Cortina PE CTRL（及 pe-ctrl/adma/pelog/ipc/sem/ca-peri）是一个片上包处理协处理器。

PE 还能做：加解密卸载、HTTP/FTP 本地收发

软件流卸载框架（FAST-PATH）

模块作用
FleetConntrack (FC)流表缓存 / conntrack 硬件卸载，钩子进 netfilter 缓存转发信息，提供 rtk_fc_fastfwd_netif_rx / napi_gro_receive 快速路径
RomeDriver (RG)L3 路由/NAT 卸载引擎（含 ALG、IGMP snooping、WMUX 等）
Switchdev标准 Linux switchdev 卸载
SMP IPI 分流多核 RX/TX 负载均衡：RTK_L34_FC_IPI_NIC_RX/TX、RTK_L34_FC_IPI_WIFI_RX/TX（wifi rx ring 默认 2^12）

FC 还提供 per-HW flow MIB（RTK_FC_PER_HW_FLOW_MIB，依赖 8277C/9607F 系列）来统计硬件流表计数。

无线侧卸载

  • HWNAT（硬件 NAT）卸载

  • WiFi AMSDU offload by PE：把 802.11 聚合交给 PE 硬件

  • WiFi Tx/Rx 负载均衡：FC_WIFI_TX/RX_* 选择 GMAC0/1/2 自动选路或 hash 分担（5G 可跨多 GMAC trunking）

  • WiFi 驱动侧还有MAC HAL 卸载接口、WiFi HWNAT 卸载

网络加速由 Cortina NI + PE 硬件转发引擎，配合 Realtek 自研的 FleetConntrack 流卸载 / RomeDriver 路由卸载框架；无线卸载走 FC-WLAN-HWNAT 与 PE-AMSDU-offload；PE 充当片上轻量包处理协处理器。
